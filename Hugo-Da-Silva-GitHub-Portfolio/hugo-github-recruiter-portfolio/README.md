# Hugo da Silva — Recruiter Portfolio

A responsive, static portfolio focused on SaaS Customer Support, Technical Support, Customer Onboarding, and Customer Experience.

## Files
- `index.html` — page content
- `styles.css` — navy/teal responsive design
- `script.js` — mobile navigation, expandable work history, and case-study interactions
- `assets/banner.svg` — editable vector banner
- `Hugo-Da-Silva-CV.pdf` — recruiter-friendly PDF CV

## Publish with GitHub Pages
1. Create a repository named `trindadeproduction-maker.github.io` (confirm that this matches your GitHub username).
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. Wait for deployment, then open the URL shown on the Pages settings screen.
6. Test every link and the PDF download on desktop and mobile.

## Before publishing
- Confirm the Decathlon employment dates. The source CV lists February 2018–October 2021 and also November 2025–present; the website flags this for verification.
- Confirm each language proficiency level. Levels were omitted because the source CV's labels were not clearly mapped to each language.
- Check the tools list and spellings against your actual experience.
- Replace or remove any details you do not want publicly visible.
- Do not add confidential employer or customer information.
- The case studies are explicitly labeled illustrative exercises; keep them that way unless you replace them with verified, anonymized work examples.

## Customization
Edit `index.html` for text, `styles.css` for colors/layout, and `script.js` for interactions. The site uses no framework, build step, API key, or server-side code. Google Fonts are optional; system fonts will be used if the font service is unavailable.
